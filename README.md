# 🛒 PrimeKarts - Full-Stack Amazon Clone

PrimeKarts is a fully responsive, full-stack e-commerce web application inspired by Amazon. It allows users to browse products, manage their shopping cart, and experience a seamless online shopping interface built with modern web technologies.

---

## 🚀 Live Demo
🌐 **Live Website:** [https://primekarts.onrender.com](https://primekarts.onrender.com)

---

## ✨ Features

*   **Responsive UI/UX:** Designed to look and feel like Amazon, optimized for both desktop and mobile devices.
*   **Product Catalog:** Browse through various categories of products with clean layouts and styling.
*   **Dynamic Shopping Cart:** Add products, update quantities, and calculate total prices dynamically.
*   **User Authentication:** Secure signup and login functionality using JWT (JSON Web Tokens).
*   **Database Integration:** Powered by MongoDB Atlas to store user data and product details securely.

---

## 🛠️ Tech Stack

*   **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
*   **Backend:** Node.js, Express.js
*   **Database:** MongoDB Atlas (Mongoose)
*   **Hosting & Deployment:** Render
